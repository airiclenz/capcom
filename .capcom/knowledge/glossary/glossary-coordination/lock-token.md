---
title: "Lock token: what a Tree lock holder presents to renew or release it; capcom keeps it for the session"
---

What a holder receives when it takes a **Tree lock** and presents to renew or release it. capcom
keeps it for the session in a token file keyed by worktree and purpose, so naming the same purpose
again resumes the lock and prints the token again. It is a public signal between agents, not a
secret: it tells different work apart, not who may touch the worktree.
_Avoid_: session id, key
