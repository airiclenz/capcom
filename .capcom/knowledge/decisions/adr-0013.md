---
title: capcom ui shows the Tree lock and asks before writing while another session holds it
---

Status: Accepted.

`capcom ui` is the first capcom writer that checks the Tree lock: it always shows the lock's
state, and when another session holds this worktree's lock it asks before every write. It never
acquires, touches or releases the lock itself. Read `adr-0013-decision` for the behaviour and why,
then `adr-0013-rejected` for blocking writes, ignoring the lock, and taking it.
