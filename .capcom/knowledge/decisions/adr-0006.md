---
title: Migration is agent-written files checked by capcom, not an importer
---

Status: Accepted.

capcom ships no importer for beads or any other tracker. Because the store is plain markdown
files, a migration is an agent writing those files by following a written guide
(`docs/site/getting-started/migrating-from-beads.md`, with the field mapping), and
`capcom check` proving the result valid with `path:line` errors the agent can fix in a loop. This keeps capcom free of any
dependency on another tool's export format, leaves the one judgment step (choosing a meaningful
slug for every legacy hash id) to an agent instead of a title heuristic, and avoids a code path
used once per repository. The cost falls on other beads users, who follow the guide instead of
running one command.
