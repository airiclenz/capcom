---
title: The directory tree is the hierarchy
---

Status: Accepted.

capcom stores Issues and Knowledge as the directory tree itself: a node is a file named after its
id, its children sit in a sibling directory of the same name, and a move is a plain rename. Read
`adr-0001-decision` for the rule and its reasons, then `adr-0001-rejected` for the `parent:` field
alternative.
