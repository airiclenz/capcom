---
title: capcom ui remembers its layout in a machine-written state.yaml beside the hand-owned config.yaml
---

Status: Accepted.

`capcom ui` remembers the sidebar width between runs in a second per-user file,
`<os.UserConfigDir>/capcom/state.yaml`, which only it writes; the user config `config.yaml`
(ADR 0011) stays hand-owned and is never rewritten. Read `adr-0014-decision` for the file, when it
is written and how it is read, then `adr-0014-rejected` for rewriting `config.yaml` in place, a
share-of-width unit, and writing on quit.
