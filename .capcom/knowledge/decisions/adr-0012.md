---
title: The CLI and the UI share one write path in an ops package
---

Status: Accepted.

The write logic that today sits privately in `internal/cli` (editing a node with an ETag, closing
with its newly-ready result, logging, dependency changes) moves into a shared package, working name
`internal/ops`, that both the CLI and `capcom ui` call. Read `adr-0012-decision` for what moves and
why, then `adr-0012-rejected` for driving `cli.Run` in process and copying the glue into the UI.
