---
title: capcom does not serve its operations over MCP for now
---

Status: Proposed.

capcom stays a CLI that agents drive through shell commands; it does not ship a `capcom mcp`
server that exposes its operations as Model Context Protocol tools. The eval numbers show flag
syntax and shell quoting are not where agents lose time: call count is, and `capcom apply`
answers that. The record is reopened when an eval run shows otherwise. Read `adr-0018-decision`
for the server this would be, what it costs, the numbers and the revisit trigger, then
`adr-0018-rejected` for building it now, a read-only server and a generated tool list without a
server.
