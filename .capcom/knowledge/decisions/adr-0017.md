---
title: A CLI write warns while another session holds the Tree lock, unless it writes the Issue the lock is held for
---

Status: Accepted.

A mutating CLI command still writes while the Tree lock of this worktree is held, but it now says
so: it adds one warning naming the holder and the purpose, unless the write targets the Issue whose
id is the lock's purpose. It never refuses a write and never changes an exit code. Read
`adr-0017-decision` for when it warns, where the warning goes and why, then `adr-0017-rejected` for
a `--token` flag on every write, blocking writes, a stderr-only warning and leaving the CLI silent.
