---
title: The store declares its format version, and a binary refuses a store newer than it understands
---

Status: Accepted.

`config.yaml` declares the store's format version in a top-level `format:` key, a missing key
meaning 1; every command fails on a store newer than the binary reads, `prime` only warns, and any
new key raises the format. Read `adr-0009-decision` for the rule and why `init` first wrote the key
as a comment, then `adr-0009-rejected` for strict parsing alone, ignored keys, a version per file
and a failing `prime`.
