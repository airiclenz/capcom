---
title: A per-user config holds personal settings, created only by capcom ui
---

Status: Accepted.

capcom gains a per-user config file, `<os.UserConfigDir>/capcom/config.yaml`, for settings that
belong to a person rather than a repository; v1 holds only the `ui:` section. Only `capcom ui`
reads it, and it is created the first time `capcom ui` starts, never by any other command. Read
`adr-0011-decision` for the file, its creation and why it is lenient, then `adr-0011-rejected` for
a `ui:` key in `.capcom/config.yaml`, a repo default with a user override, and environment
variables.
