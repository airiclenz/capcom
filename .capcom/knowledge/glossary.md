capcom is a cross-platform issue tracker for code repositories, built for coding agents first and
still easy for people to read. On top of the issues it records who holds the repository and keeps
the project knowledge agents need, all as plain files under git.

The glossary's sections:

- Structure: `glossary-structure`
- Work: `glossary-work`
- Coordination: `glossary-coordination`
- Knowledge: `glossary-knowledge`
- Agent interface: `glossary-agent-interface`
- Flagged ambiguities: `glossary-ambiguities`

A flagged ambiguity is a word that means something else here than it does elsewhere.
