# Architectural decision records

capcom's decision records live in Knowledge as `adr-NNNN` Notes under the `decisions` Note.

- `capcom know show decisions`: the list of records
- `capcom know show "ADR 0005"`: one record, its Status line and its reading order
- A new record takes the next number and the shape ADR 0010 gives; edit records in place under
  `.capcom/knowledge/decisions/`.
