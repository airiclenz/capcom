---
title: A store format is raised only by capcom upgrade
---

Status: Accepted.

A write that needs a newer store format than `config.yaml` declares no longer raises the format
on its own: it fails with code `invalid`, writes nothing, and names `capcom upgrade`. The format
is raised only by `capcom upgrade [--format <n>]`, which defaults to the newest format, does
nothing on a store already at or above the target, and never lowers a format. This replaces ADR
0009's implicit raise; the rest of ADR 0009 stands. Read `adr-0019-decision` for the failure,
its hint, the command and why.
