title: "The repo owns its release pipeline: two committed skills write the notes, a Go dev tool publishes"
---

Status: Accepted; amended 2026-10-12, 2026-10-13 and 2026-10-16.

A capcom release is cut from a clone of this repository: two committed skills write the notes and
propose the version, and the Go dev tool `cmd/release` builds, gates on green CI and publishes to
every channel, converging when rerun. Read `adr-0008-decision` first, then `adr-0008-amend-1012` for
the `repo` test seam, then `adr-0008-amend-bumptest` for the one test that runs `git`, then
`adr-0008-amend-makefile` for the local `Makefile`, then `adr-0008-rejected` for a hidden
subcommand, CI publishing, a Makefile on the release path, granular verbs and one agent host.
