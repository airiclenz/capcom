Problem. The index still re-derives membership facts three ways, runs DecideMembership twice per refresh, and rebuilds facts lossily (every node below a repeated id is marked parsed, duplicates.go:154), which is the divergence logged on membership-owner.

Solution. tree exports its scan; the index plugs in a reader that answers clean files from rows and persists the verdict; check and agents read the verdict instead of parsing errors back.

  • Locality: facts gathered in one place
  • Tree and index agree by construction
  • index/walk.go shrinks to stat-and-cache
  • One spelling of the fact key
  • Closes membership-owner acceptance
Inside ADR-0001 and ADR-0002; ADR-0007 keeps tests on real files and SQLite. Builds on candidate 3's kind reader.
