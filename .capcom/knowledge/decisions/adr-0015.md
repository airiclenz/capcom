---
title: capcom ui remembers its tab and selections per worktree in a ui-state.yaml under the git dir
---

Status: Accepted; amended 2026-10-26.

`capcom ui` reopens, per worktree, on the tab it was on and with the issue or Note it had selected
on each tab. It keeps them in `<git-dir>/capcom/ui-state.yaml`, beside the index: never committed,
and the one file capcom ui writes inside a repository's git dir. The sidebar's width stays in the
per-user `state.yaml` (ADR 0014). Read `adr-0015-decision` for the file, when it is written and how
it is read, then `adr-0015-amend-1026` for `closed`, the Closed tab's name, then `adr-0015-rejected`
for one global file keyed by repository path, folding it into `state.yaml`, and writing on quit.
