Status: Accepted.

capcom ships a base set of Knowledge Notes, kept as markdown files and embedded in the binary;
`capcom know seed` adds the ones a store lacks. The binary is the only source of the set. A seeded
Note is the repository's own and is never overwritten, except by `capcom know seed --update` while
its text is still the text it was seeded with. Two Labels mark a seeded Note, so the store format
does not change, and where a seeded Note contradicts the repository's own Notes, the repository's
rule wins. Read `adr-0020-decision` for the set, its source, the Labels, the update and why.
