---
title: Issues are versioned with the code, and a central store stays possible
---

Status: Accepted; amended 2026-10-11.

Issue files live in the working tree and travel with the code, so capcom reports the checked-out
branch's state and git is the only sync path; `ready` and `prime` warn about changes on other
branches without merging them, and a central store stays possible as a later mode. Read
`adr-0004-decision` first, then `adr-0004-amend-1011` for remote-tracking branches in that scan,
then `adr-0004-rejected` for a store outside git and merged branch state.
